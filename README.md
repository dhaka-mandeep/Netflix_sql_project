Project Overview

This project involves an in-depth analysis of Netflix’s movies and TV shows dataset using SQL. The objective is to extract actionable insights by solving real-world business problems related to content distribution, ratings, genres, regional trends, and audience targeting. The project demonstrates strong skills in data querying, aggregation, window functions, and analytical problem-solving.

Tools & Technologies

SQL (PostgreSQL)
Data Cleaning & Transformation
Aggregations, Joins, CTEs, Window Functions
String Manipulation & Date Functions

Key Business Problems & Solutions

Analyzed the distribution of content types (Movies vs TV Shows) using aggregation queries.
Identified the most frequent content ratings for movies and TV shows using CTEs and window functions.
Extracted movies released in specific years to analyze yearly release trends.
Determined the top contributing countries by total content count.
Identified the longest movie by parsing and sorting duration values.
Analyzed recently added content (last 5 years) using date conversions.
Retrieved content by specific directors using string splitting techniques.
Identified long-running TV shows with more than five seasons.
Performed genre-wise content analysis using array unnesting.
Analyzed yearly content release trends for Indian productions and ranked top years.
Filtered documentary movies based on genre classification.
Identified missing data by locating content without director information.
Analyzed actor appearances over time for trend identification.
Ranked top actors based on appearances in Indian-produced movies.
Categorized content based on keyword analysis to assess thematic patterns.

Key Insights & Findings

Netflix offers a diverse catalog with balanced representation of movies and TV shows.
Certain ratings dominate each content type, indicating targeted audience segmentation.
Content contribution varies significantly by country, with India emerging as a key producer.
Genre and keyword analysis reveals trends in content themes and viewer preferences.
Recent content trends highlight Netflix’s strategic focus on regional and long-form content.
